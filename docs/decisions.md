# 決定事項（Decision Log）

決めたことと、その理由を残す。後から「なぜそうしたか」を追えるようにする。
新しい決定は上に追記する。

## 2026-09-07: 初期ドキュメント一式を作成

- **決定:** リポジトリに docs/ 一式と CLAUDE.md / AGENTS.md を置き、仕様とコードを同じ非公開GitHubリポジトリで管理する。
- **理由:** Claude Code と Codex の両方が同じ資料を読めるので、方針の食い違いを減らせる。チャット履歴だけを引き継ぎ資料にしない。

## 2026-09-07: 公開IDは運営内部だけで管理し、利用者同士は追跡できない

- **決定:** 公開IDも毎月変更する。内部IDは画面・公開URLに一切出さない。利用者は前月の人をサービス内でたどれない。
- **理由:** 「毎月の出会い直し」を徹底するため。ユーザーがID検索で再フォローできる案もあったが、それだと再特定ができてしまうため不採用。約束するのは「サービス内で前月のアカウントをたどれないこと」まで。
- **トレードオフ:** 気の合う人を失う寂しさは強くなる。これは検証すべき仮説として受け入れる。

## 2026-09-07: 継続アカウントと月次公開プロフィールを分離

- **決定:** 「継続するログイン用アカウント（内部）」と「毎月消える公開プロフィール」をデータ構造として分ける。
- **理由:** 同じメールでログインできつつ、利用者からは毎月新しい人物に見える、という核となる体験を実現するため。

## 2026-09-07: まずWebのみ・テキストのみのMVP

- **決定:** iPhone/Androidネイティブアプリは作らず、スマホブラウザで使えるWeb版から。投稿はテキストのみ。
- **理由:** 資金が限られる中、最小コストで「翌月また来たくなるか」を検証するため。
